# EPC 2026 Photo Gallery

Photo gallery of the European Population Conference 2026 (Bologna, 3–6 June 2026),
published via GitHub Pages.

- `index.html` — gallery page (day tabs, lazy-loaded grid, lightbox)
- `manifest.js` — list of photo filenames per day
- `photos/` — display-size images (max 1600 px)
- `thumbs/` — grid thumbnails (max 480 px)

The full-resolution originals live in the local `EPC 2026/` folder, which is
excluded from the repository via `.gitignore`.
